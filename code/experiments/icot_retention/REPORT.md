# 기존 ICoT가 맞히던 문제를 지키면서 MMMU 정답 수를 늘릴 수 있을까?

## 1. 실험 목적

이번 실험 환경에서 기존 ICoT는 MMMU 900문항 중 **500개**를 맞혔습니다.

이번 목표는 **MMMU에서 새로 맞힌 수가 기존 정답을 놓친 수보다 많아져 501개 이상을 맞히는 것**이었습니다. 이를 위해 전문적인 그림을 읽는 훈련 문항을 늘리고, 기존 ICoT가 맞힌 훈련 문항에서는 **어떤 보기를 얼마나 유력하게 봤는지**도 배우게 했습니다. 이하 **교사 모델**은 고정한 기존 ICoT이고, **학생 모델**은 같은 가중치에서 출발해 추가 학습한 모델입니다.

팀이 발표한 가중치 `icot/adapters/498`를 병합해 교사 모델로 사용했습니다. 팀의 원래 발표 기록은 498/900이고, 아래 비교의 기준은 이번 환경에서 같은 가중치를 재평가한 500/900입니다. [팀 ICoT 발표 기록](../../icot/README.md) · [이번 환경의 재평가](evidence/summary.json)

## 2. 어떤 데이터로 학습했는가

출발점인 A-OKVQA·M³CoT 구성에서는 상식 문항이 전체의 70.2%였습니다. 여러 전공의 시각 자료를 다루는 MMMU에 맞춰 A-OKVQA 3,000개를 줄이고, 과학 도표와 생의학 영상 문항을 각각 1,500개씩 넣었습니다. **훈련 문항 수는 18,956개로 유지했고 상식 문항 비중은 54.3%로 낮췄습니다.** [훈련셋 구성 기록](DATA.md)

| 훈련 자료 | 문항 수 | 학생 모델이 연습할 내용 |
|---|---:|---|
| A-OKVQA | 8,983 | 일상 사진 속 단서와 상식을 결합해 답하기 |
| M³CoT | 6,973 | 그림을 근거로 과학·수학·상식 문제 풀기 |
| SciVQA | 1,500 | 과학 논문의 그래프와 도표에서 수치·관계 읽기 |
| PMC-VQA v2 | 1,500 | 생의학 논문의 그림과 영상에서 전문적인 시각 단서 식별하기 |

네 자료 모두 공식 훈련 분할에서 고른 객관식입니다. 입력은 **이미지·질문·보기**, 학생 모델이 출력하도록 가르친 답은 **정답 글자**입니다. M³CoT의 풀이 과정은 학습에 사용하지 않았습니다.

## 3. 무엇을 어떻게 학습했는가

먼저 교사 모델에 훈련 문항의 이미지·질문·보기만 주고 풀게 했습니다. 교사 모델이 각 보기에 준 확률을 저장하고, 가장 확률이 높은 보기를 정답표와 대조했습니다. 교사 모델은 **13,821개를 맞혔고 5,135개를 틀렸습니다.** [교사 모델 판정 기록](evidence/teacher_train.json)

학생 모델에서는 세 부분을 함께 학습했습니다. 이미지를 읽는 **vision encoder**, 이미지 특징을 언어 모델에 전달하는 **merger**(최종 1개와 중간 3개), 그리고 언어 모델 36개 층의 **attention Q·K·V·O에 새로 붙인 LoRA**입니다. 언어 모델의 기존 가중치는 고정했습니다. LoRA가 처음에 더하는 보정값은 0이므로, 학생 모델은 교사 모델과 같은 동작에서 출발했습니다. [학생 모델 학습 설정](training/model.py)

### 한 문항으로 이해하는 학습 손실

실제 훈련셋에 **“그림 속 두 자석은 서로 끌어당기는가(A), 밀어내는가(B)?”**라는 문항이 있습니다. 정답은 **B**입니다. 아래 예시에서 **교사 모델의 확률은 실제 기록**이고, **학생 모델의 확률은 설명을 위한 가정값**입니다. [교사 모델의 문항별 기록, ID `m3cot:physics-1499`](evidence/teacher_train.jsonl.gz)

**① 정답 손실 — 학생 모델이 정답 B를 얼마나 잘 출력하는가?**

학생 모델은 답을 토큰 단위로 출력합니다. 각 위치에서 **실제로 다음에 나와야 할 토큰에 준 확률**을 $r_t$, 정답 글자와 답변 종료 표기를 포함한 응답 토큰 수를 $T$라고 하면, 정답 손실은 다음과 같습니다.

$$
L_{\mathrm{CE}}=\frac{1}{T}\sum_{t=1}^{T}(-\ln r_t).
$$

읽는 방법은 간단합니다. **정답 토큰에 높은 확률을 주면 손실이 작아지고, 낮은 확률을 주면 커집니다.** 자석 문항에서 학생 모델이 전체 어휘 중 첫 토큰 B에 0.48, 이어지는 두 응답 토큰에 각각 0.90, 0.95를 줬다고 하겠습니다. 그러면 정답 손실은 세 토큰의 손실을 평균한 값입니다.

$$
L_{\mathrm{CE}}
=\frac{-\ln 0.48-\ln 0.90-\ln 0.95}{3}
\approx \mathbf{0.297}.
$$

이 계산은 교사 모델의 정오와 관계없이 **18,956문항 전체**에 적용합니다.

**② 증류 손실 — 학생 모델이 A와 B를 비교한 방식도 교사 모델과 비슷한가?**

이번에는 **답의 첫 글자를 고르는 순간**만 봅니다. 학생 모델이 전체 어휘 중 A에 0.32, B에 0.48을 줬다면, 두 보기에 준 확률의 합은 0.80입니다. 따라서 **A와 B 안에서만 비교한 비율**은 A가 $0.32/0.80=40\%$, B가 $0.48/0.80=60\%$입니다.

| 자석 문항의 보기별 확률 | A · 끌어당긴다 | B · 밀어낸다 |
|---|---:|---:|
| 교사 모델 · 실제 기록 | 18.2% | **81.8%** |
| 학생 모델 · 계산 예시 | 40.0% | **60.0%** |

두 모델 모두 B를 골랐지만, 학생 모델은 A도 상당히 유력하게 봤습니다. **정답 손실은 정답 B에 준 확률을 사용하고, 증류 손실은 표의 두 행 전체를 비교합니다.**

보기 $c$에 준 교사 모델의 확률을 $p_c$, 학생 모델의 확률을 $q_c$라고 하면, 증류 손실은 다음과 같습니다. 교사 모델이 맞혔을 때 두 분포의 차이를 재는 식을 **KL 발산**이라고 합니다.

$$
L_{\mathrm{KD}}=
\begin{cases}
\displaystyle\sum_{c\in\text{보기}}p_c\ln\!\left(\frac{p_c}{q_c}\right),
& \text{교사 모델이 맞힌 문항},\\[5pt]
0, & \text{교사 모델이 틀린 문항}.
\end{cases}
$$

자석 문항은 교사 모델이 맞혔으므로 A와 B의 값을 각각 계산해 더합니다.

$$
L_{\mathrm{KD}}
\approx 0.182\ln(0.182/0.40)+0.818\ln(0.818/0.60)
\approx \mathbf{0.110}.
$$

두 모델의 보기별 확률이 일치하면 이 값은 0입니다. 반대로 **교사 모델이 틀린 5,135문항에서는 처음부터 증류 손실을 0으로 둡니다.** 그 문항에서는 학생 모델이 교사의 오답을 따라 배우지 않고 정답 손실만으로 학습합니다.

**③ 학습 손실 — 정답 손실과 증류 손실을 합쳐 가중치를 바꾼다.**

$$
L_{\mathrm{문항}}=L_{\mathrm{CE}}+\lambda L_{\mathrm{KD}}.
$$

$\lambda$는 **증류 강도**입니다. 자석 문항에서 $\lambda=0$이면 정답 손실 **0.297**만 사용합니다. $\lambda=0.5$이면 두 손실을 합친 값은 **$0.297+0.5\times0.110\approx0.352$**입니다. 교사 모델이 틀린 문항은 증류 손실이 0이므로 어느 강도에서도 정답 손실만 남습니다.

한 번에 학습하는 문항 수를 $N$이라 하면, 학생 모델은 **전체 $N$문항의 평균 손실**이 줄어드는 방향으로 vision encoder·merger·LoRA를 동시에 업데이트합니다. [손실 계산 코드](training/trainer.py)

$$
L_{\mathrm{배치}}=\frac{1}{N}\sum_{i=1}^{N}L_{\mathrm{문항},i}.
$$

이 방식으로 **증류 강도 0, 0.1, 0.25, 0.5**를 비교했습니다. 네 학생 모델은 같은 시작 가중치와 훈련 문항으로 각각 한 에포크, **2,370스텝**을 학습했습니다. 따라서 **교사 모델은 추가 학습 전 기준**이고, **학생 모델 λ=0은 같은 양을 추가 학습하되 증류를 사용하지 않은 비교 조건**입니다.

## 4. 어떻게 모델을 고르고 최종 평가했는가

1. **A-OKVQA·M³CoT 검증셋 1,044개로 학습 시점을 골랐습니다.** A-OKVQA 660개와 M³CoT 384개를 공식 훈련 분할에서 미리 떼어 두었습니다. 각 증류 강도에서 다섯 학습 시점의 가중치를 평가해 가장 많이 맞힌 시점을 선택했습니다. 정답 수가 같으면 교사 모델의 기존 정답을 덜 놓친 시점, 그 수도 같으면 더 이른 시점을 골랐습니다.
2. **EMMA 검증셋 320개를 더해 대표 모델을 골랐습니다.** EMMA 공식 공개 test에서 수학·물리·화학·코딩 객관식을 각 80개씩 선별했습니다. 첫 단계에서 선택한 가중치를 이 문항들에서도 평가한 뒤, **두 검증셋 정확도에 각각 50%**를 부여해 증류 후보 중 대표 모델을 골랐습니다. 평균 정확도가 같으면 두 검증셋 중 개선 폭이 작은 쪽을 비교해 그 값이 큰 후보를 골랐습니다. 그래도 같으면 기존 정답을 놓친 비율의 평균이 더 낮은 후보, 마지막으로 증류 강도가 더 작은 후보 순입니다. 이번에는 무증류를 포함해도 같은 모델이 선택됐습니다. 두 검증셋에서는 보기별 확률이 가장 높은 보기를 예측으로 삼았습니다. [모델 선택 기록](evidence/selection.json)
3. **대표 모델을 확정한 뒤 MMMU 900문항으로 최종 평가했습니다.** 사용한 데이터는 **MMMU 공식 validation 전체**입니다. 네 학생 모델 모두 30과목의 객관식 847개와 주관식 53개에 답을 직접 생성했고, 교사 모델과 같은 채점기로 채점했습니다. [MMMU 평가 설정](../../configs/evaluation.toml)

## 5. 결과는 무엇을 보여 주는가

**어느 학생 모델이 선택됐는가?** λ=0.5가 두 검증셋 모두에서 가장 많이 맞혀 대표 모델로 선정됐습니다. 교사 모델보다 각각 **25개**, **5개** 더 맞혔습니다.

| 모델 | 선택한 학습 스텝 | A-OKVQA·M³CoT 검증셋 /1,044 | EMMA 검증셋 /320 |
|---|---:|---:|---:|
| 교사 모델 | — | 813 | 121 |
| 학생 모델 λ=0 | 2,370 | 837 | 119 |
| 학생 모델 λ=0.1 | 2,000 | 831 | 116 |
| 학생 모델 λ=0.25 | 1,500 | 834 | 121 |
| **학생 모델 λ=0.5** | 2,370 | **838** | **126** |

**MMMU에서도 500개를 넘었는가?** 대표 모델은 **488개**를 맞혔습니다. 교사 모델이 틀린 400개 중 **31개를 새로 맞혔지만**, 교사 모델이 맞혔던 500개 중 **43개를 놓쳤습니다**. 따라서 최종 정답 수는 **500 + 31 − 43 = 488개**입니다.

| 모델 | 새로 맞힌 수 | 기존 정답을 놓친 수 | MMMU 정답 수 /900 |
|---|---:|---:|---:|
| 교사 모델 | — | — | **500** |
| 학생 모델 λ=0 | 40 | 52 | 488 |
| 학생 모델 λ=0.1 | 34 | 48 | 486 |
| 학생 모델 λ=0.25 | 36 | 42 | **494** |
| **학생 모델 λ=0.5 · 대표 모델** | **31** | **43** | **488** |

**증류를 더하면 무엇이 달라졌는가?** 같은 2,370스텝에서 λ=0과 λ=0.5를 비교하면, λ=0.5는 기존 정답을 **9개 덜 놓쳤습니다**(52→43). 하지만 교사 모델의 오답을 **9개 덜 고쳤습니다**(40→31). 기존 정답을 더 지킨 만큼 새로 맞히는 문항이 줄어, 두 학생 모델의 총점은 모두 488개였습니다. [최종 비교 결과](evidence/summary.json)

**결론적으로, 대표 모델의 검증셋 개선은 MMMU 전체 정확도의 향상으로 이어지지 않았습니다.** MMMU 평가 후 확인한 최고 점수도 λ=0.25의 494개로, 교사 모델보다 6개 낮았습니다.
